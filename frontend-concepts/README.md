# TECHBISS — Phase 1 Frontend Concepts

Five genuinely different premium visual directions for TECHBISS, a fictional
$10B+ global digital transformation platform. Each concept is a single
self-contained HTML file — no build step, no external JS libraries, only a
Google Fonts stylesheet as an external resource — implementing the same 14
"pages" (Home, Services, Solutions, Marketplace, Product Detail, Work,
Process, About, Resources, Pricing, Contact, Login, Installer, Dashboard
Preview) via client-side hash routing, so each file is one shareable URL that
behaves like a real multi-page site.

Every concept includes: dark + light modes with a persisted toggle, an
animated intro/loader, scroll-triggered reveals and animated counters, a
draggable/swipeable carousel, a working Marketplace browse → preview →
purchase flow, a 7-step Installer wizard (Select → Detect → Configure →
Import/Migrate → Install → Verify → Launch) with simulated live progress, a
3-role (Admin/Client/Staff) Dashboard preview with hand-built charts, a
polished login screen, and full keyboard/reduced-motion accessibility
support. Phase 1 is frontend-only — nothing here talks to a real backend.
