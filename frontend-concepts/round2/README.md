# TECHBISS — Round 2: Bright/Colorful Directions

The Phase 1 round 1 concepts (`../01-obsidian-prestige.html` through
`../05-monolith-systems.html`) were rejected for being uniformly dark,
muted, and editorial. This round goes the opposite direction: 10 genuinely
different bright, colorful, high-energy style types, each a single
self-contained HTML page (no build step, only a Google Fonts stylesheet as
an external resource).

Scope note: to react quickly across 10 directions, each file here is a rich
**single scrollable landing page** (nav, hero, services, solutions,
marketplace teaser with a working preview/purchase modal, process, case
studies, pricing, FAQ, contact, footer) rather than the full 14-route
multi-page app built for round 1. Once you pick 1-3 directions you like,
those get built out as the full multi-page app (2 variants each).
