(assets/images/brand/) so every platform matches. Sizes follow each
platform's current (2026) upload recommendations.

(same drawing code as tools/make-brand-assets.php — change the brand colours
in one place and both scripts stay in step)

About the WhatsApp cover: neither the WhatsApp nor WhatsApp Business app has
a cover-photo slot of its own — only the circular profile picture. The
1200x600 image above is for the tools that DO show a banner on a
WhatsApp-linked page (a WhatsApp Business API provider's hosted profile, a
link-in-bio page, a CRM chat widget) — keep it on hand for whichever one
gets used, and skip it if none of that applies.

Not included: TikTok has no cover-photo concept either — only a profile
picture.
